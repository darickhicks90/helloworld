KIOSKS (things you use with A)
Size:    up to 64 x 64 px; 16-32 px wide fits a person-sized world.
Format:  PNG with transparency; bottom-centre anchor, like props. Solid by default.
In the Builder each kiosk has a job:
  SIGN      shows its text.
  SHOP      sells an item for coins (set the item and the price).
  CHEST     gives an item once.
  TELEPORT  sends you to another room (pick it on the map).
  SAVE      makes this your restart point.
Any kiosk can play a sound when used.
