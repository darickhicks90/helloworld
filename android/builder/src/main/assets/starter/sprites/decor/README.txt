DECOR (you walk over or past it)
Size:    anything up to 256 x 256 px. Rugs 32-64 px, banners and windows 10-24 px.
Format:  PNG with transparency; semi-transparent pixels are fine (shadows, cobwebs).
Layer:   lies on the floor under everything by default; set "Above" in the inspector for
         things hanging overhead.
Not solid by default.
Animated: e.g. wall_torch_f3.png, candle_f2.png.
