PROPS (stand on the floor; block the way)
Size:    anything up to 128 x 128 px; most look right between 12 and 48 px wide.
         For scale: a person is 16 px tall, a pillar about 70.
Format:  PNG with transparency.
Anchor:  the BOTTOM-CENTRE of the image is the spot on the floor where it stands, so leave
         no empty rows under the base. Only the bottom of a prop blocks the way (its
         footprint), so you can walk behind tall things.
Depth:   whatever stands lower on screen is drawn in front, so you can hide behind pillars.
Scale:   each placed copy can be 0.5x to 4x; draw at the size you mostly want (1x).
Solid:   on by default; turn it off per object in the Builder's inspector.
Animated: frames side by side, name ending _f2, _f3 ... (e.g. brazier_f2.png).
